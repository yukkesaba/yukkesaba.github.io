# GraphMaker for Illustrator

Illustrator でグラフを作成し、あとから何度でも再編集できるスクリプトです。
グラフはすべて通常のパスとテキストで描画されるので、アピアランスの調整や書き出しも自由に行えます。

## インストール

1. `GraphMaker.jsx` を Illustrator のスクリプトフォルダにコピーします。
   - Windows: `C:\Program Files\Adobe\Adobe Illustrator <バージョン>\Presets\ja_JP\スクリプト\`
   - macOS: `/Applications/Adobe Illustrator <バージョン>/Presets/ja_JP/Scripts/`
2. Illustrator を再起動すると **ファイル > スクリプト > GraphMaker** から実行できます。
   （インストールしない場合は **ファイル > スクリプト > その他のスクリプト…** から直接選べます）
3. アクションに登録してファンクションキーを割り当てると便利です。

## 使い方

| 操作 | 結果 |
| --- | --- |
| 何も選択せずに実行 | 新規グラフを画面中央に作成 |
| GraphMaker のグラフ（またはその中の一部）を選択して実行 | 設定を読み込んで **再編集**。「更新」で同じ位置・同じ重ね順に描き直し |

設定はグラフのグループの「メモ（note）」に保存されるため、ファイルを保存して開き直しても再編集できます。
ダイアログの「プレビュー」でアートボード上に仮描画して確認できます。

## カスタマイズできる項目

- **データ・種類**: 棒 / 積み上げ棒 / 横棒 / 横積み上げ棒 / 折れ線 / 面。データは CSV またはタブ区切り（Excel からそのまま貼り付け可）。
  プロットのサイズ、棒の太さ（%）、棒の間隔、背景色、値ラベル（表示・小数桁・文字）
- **系列スタイル**（系列ごと）: 色、線幅、破線、枠線の色・幅、マーカー（円・四角・ひし形）とサイズ、不透明度
- **軸・目盛り**: 軸の色・太さ、X・Y 軸それぞれの軸線と目盛り線の表示、目盛りの長さ、値軸の最小/最大/間隔（空欄で自動）、小数桁、3 桁区切り、接頭辞/接尾辞（¥、% など）、
  X ラベルの回転、グリッド線（縦・横それぞれ表示切替、色・幅・破線）、X/Y 目盛り文字のフォント・サイズ・色、軸タイトル
- **タイトル・凡例**: タイトル文字とスタイル、凡例の表示・位置（右 / 上 / 下）・文字スタイル

フォントは「…」ボタンからインストール済みフォントを検索して選べます。色は `#RRGGBB` 入力か「選択…」でカラーピッカーを使います（`none` で無し）。

## データ形式の例

```
項目,2023年,2024年
A,120,150
B,80,95
C,140,
D,60,110
```

空欄の値は描画されません（折れ線はそこで途切れます）。

## 注意

- `GraphMaker.jsx` は **BOM 付き UTF-8** で保存してください。BOM なしで保存すると日本語版 Illustrator が Shift_JIS として読み込み、「ストリング定数が終了していません」エラーになります。

- 再編集すると、グラフは設定から描き直されます。グラフ内部を手作業で変更した部分は失われるので、
  最終調整は再編集が不要になってから行ってください。
- 前回使った設定は次の新規作成時の初期値として `Folder.userData/GraphMaker_prefs.txt` に保存されます。
