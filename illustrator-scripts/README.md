# 地図向け Illustrator スクリプト

PlugX-MappingTools の一部機能を参考に、ExtendScript（.jsx）で再現したものです。

| ファイル | 機能 |
|---|---|
| `テキスト原点パネル.jsx` | 文字の位置を変えずに行揃え（アンカーポイント位置）だけを変更するパネル。横組み/縦組みの切り替えもできる（切り替え時はアンカーポイント位置を保つ）。ポイント文字が対象 |
| `高速移動.jsx` | 2点のオープンパスを1つだけ選択して実行すると、1点目→2点目の分だけ、表示中かつロックされていないレイヤーの全オブジェクトを移動する |
| `配置画像サイズをリセット.jsx` | 配置画像の変形をリセット（元の縦横比・回転0・72dpi相当）。中心位置は保つ |
| `テキストを水平垂直に戻す.jsx` | 回転したテキストを、アンカーポイントを中心に水平（縦組みは垂直）に戻す |
| `テキストのシアー変形除去.jsx` | 回転・拡大縮小・文字位置はそのままにシアー成分だけ除去。パス上テキストはパスの形を保つ |

## インストール

`illustrator-scripts` フォルダの中身（`lib` フォルダも含む）を、Illustrator のスクリプトフォルダにコピーして Illustrator を再起動します。

- Windows: `C:\Program Files\Adobe\Adobe Illustrator <バージョン>\Presets\ja_JP\スクリプト\`
- Mac: `/Applications/Adobe Illustrator <バージョン>/Presets/ja_JP/スクリプト/`

コピーすると「ファイル > スクリプト」に表示されます。`lib/mapping_core.jsxinc` は各スクリプトから読み込む共通ファイルなので、必ず一緒に置いてください。

ショートカットで使いたい場合は、アクションパネルで「メニュー項目を挿入」からスクリプトを記録し、ファンクションキーを割り当てます。

## 注意

- 実行結果は Ctrl/Cmd+Z で取り消せますが、項目ごとに複数回の取り消しが必要な場合があります。
- 高速移動では、ロックされたオブジェクトと、非表示またはロック中のレイヤーは移動しません。
